# HelioGrid Complex

A fictional 2.1GW flagship solar facility, built as an interactive 3D/VR
portfolio experience. Four spatial zones — Aerial Overlook, Array Ring Alpha,
HelioSpire Tower, Subterranean Vault — reachable from a landing hologram
terminal, fully usable on desktop/mobile and progressively enhanced with
WebXR for VR headsets.

## Status

Context/planning stage — no app code yet. This repo currently holds the
context an AI coding agent (or a human) needs to start the build correctly.

## Start here

If you're an agent picking this up: read **`AGENTS.md`** first, in full,
before touching anything else.

If you're a human: `docs/00-project-lore.md` is the canonical facility spec
and experience structure. The rest of `docs/` covers the problem statement,
design principles, tech stack, target architecture, and git workflow.
`docs/04-architecture.md`'s "Build order" section is the actual plan.
